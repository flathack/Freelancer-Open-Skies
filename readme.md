# Freelancer: Open Skies

**A Godot port of the Freelancer (2003) engine — in development, coming soon.**

Open Skies rebuilds the engine behind Microsoft's and Digital Anvil's space classic in [Godot 4](https://godotengine.org/) and C#, so Freelancer can be played on a modern, open engine. It reads the data files of your own Freelancer installation directly: systems, ships, models, textures, sounds and missions all come from the original game.
